# Ziguza
Ziguza Jailbreak Tool

## 📲 How to Install

Due to installation limitations, this app is distributed as a **configuration profile**.

### 🚀 Steps

1. **Download the latest version**
   - Go to the **Releases** section and download the latest version.

2. **Open the file**
   - Locate the downloaded `.mobileconfiguration` file on your iPhone.
   - Tap to open it.

3. **Install the profile**
   - Navigate to:
     ```
     Settings → General → VPN & Device Management → Ziguza → Install
     ```

---

> ⚠️ **Note:** You may be prompted to enter your device passcode during installation.
